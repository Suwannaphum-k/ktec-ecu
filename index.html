เชื่อมต่อ ECU

        
การอ่านและเขียนค่าจริงต้องใช้ Web Serial (สาย USB-OTG) หรือ Web Bluetooth บน Chrome Android หน้านี้เปิดอยู่ในกรอบที่บล็อกอุปกรณ์ ปุ่มด้านล่างจึงทดสอบได้แค่ว่าเบราว์เซอร์รองรับไหม
